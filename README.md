# streamlined-weather
Streamlined Weather info, right on your desktop
## The Problem
Most weather apps are clunky, with bloated User Interfaces.
## How It Works
Streamlined Weather intends to simplify user experience
Get the info you want, instantly
## Roadmap
MVP goal - allow user to access weather info of their choosing for a location they enter
Future plans - more user customizability, scheduling of info sending
## Tech Stack
Utilizes:
-Bash
-curl
-grep
-awk
-weather API
